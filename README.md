# 三國誌版皇室戰爭 — POC v1.1

Playable dual-track prototype (**軍令** deploy + **士氣** stratagems).

**Live:** https://mangohk.github.io/3cntywar/

Open `index.html` or use any static server. Controls: 開戰 → select card → deploy left/right → click own unit to cast when 士氣 is ready.

Files: `index.html`, `style.css`, `game.js`.
